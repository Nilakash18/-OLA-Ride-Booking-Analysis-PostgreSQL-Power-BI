This project analyzes Ola ride booking data using PostgreSQL to answer key business questions related to bookings, revenue, cancellations, customer behavior, vehicle performance, payment methods, ride distance, and customer satisfaction. The analysis consists of 20 real-world SQL queries using aggregate functions, filtering, grouping, sorting, date/time functions, and conditional logic to generate actionable business insights. The project demonstrates practical SQL skills commonly used by Data Analysts to support data-driven decision-making.
